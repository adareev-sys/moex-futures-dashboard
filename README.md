# Фьючерсы МосБиржа — спреды

Дашборд спредов фьючерсов FORTS (МосБиржа): котировки собираются раз в час
GitHub Actions через бесплатный ISS API, сигналы расхождения/сужения спреда
дублируются уведомлениями в Telegram.

- **Дашборд (сайт):** GitHub Pages → `index.html` + `data.json`
- **Сигналы:** расхождение соседних контрактов > 2% — «open» (зелёный),
  сужение < 1% — «close» (красный). Сравниваются только соседние фьючерсы
  по дате экспирации (1–2, 2–3, …).
- **Группы:** BR (Brent), NG (газ), Si (USD/RUB), MX (индекс), GD (золото), CR (CNY/RUB).

## Как это работает

| Файл | Роль |
|---|---|
| `update.py` | раз в час: котировки, часовые свечи (12 недель), спреды, сигналы → `data.json` |
| `notify.py` | отправка новых сигналов в Telegram (текст + график пары) |
| `.github/workflows/update.yml` | расписание cron + запуск скриптов + коммит данных |
| `signals_state.json` | состояния пар для детекции новых сигналов |
| `chat_id.txt` | ваш chat_id в Telegram (подхватывается автоматически) |

## Секреты (Settings → Secrets → Actions)

- `TELEGRAM_TOKEN` — токен бота от @BotFather
- `CHAT_ID` — необязательно: если пусто, берётся из последнего сообщения боту

## Запуск вручную

Actions → «Обновление котировок и сигналов» → Run workflow.
